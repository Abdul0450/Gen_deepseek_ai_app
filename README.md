🚀 Generative AI Code Companion
An AI-powered coding assistant built using DeepSeek, Ollama, and LangChain to enhance software development by providing code generation, debugging, documentation, and solution design capabilities.

🌟 Project Overview
This Generative AI application serves as a pair programmer that assists developers with:
✅ Writing and optimizing Python code
✅ Debugging errors and suggesting fixes
✅ Generating high-quality documentation
✅ Providing structured solutions for coding problems

With DeepSeek-r1:1.5B and DeepSeek-r1:3B, this tool leverages LLM-powered capabilities to improve developer productivity.

🔥 Key Features
🚀 Python Expert – Generates efficient Python code snippets.
🔍 Debugging Assistant – Identifies and fixes coding errors.
📜 Code Documentation – Provides meaningful explanations and docstrings.
🛠 Solution Design – Helps structure code and suggest best practices.

🏗 Technology Stack
DeepSeek (LLM for intelligent coding)
Ollama (LLM model deployment)
LangChain (LLM-based AI framework)
FastAPI / Streamlit (for API and UI)
